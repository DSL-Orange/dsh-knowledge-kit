> **这是"知识库管理本身"的地方**，不是知识内容区。

## 一、这里放什么

| 放 | 例 |
|---|---|
| **管理动作的记录与判断** | 加工笔记、审计记录、决策理由 |
| **管理机制的文档** | 记录机制、维护流程、路测方法 |
| **管理工具的使用说明** | 检查器判据、坑记录 |

## 二、不放什么（边界）

| 不放 | 去哪 |
|---|---|
| 知识内容（DSH 是什么、怎么装插件） | `10-概念/` `20-操作/` |
| 项目档案（某项目做了什么） | `40-项目/` |
| 素材、纸条、报告投递 | `_信箱/` |

> **判据**：**"读它的人是来管库的，还是来用库的？"** 前者进这里，后者不进。
