# 维护报告区

> 用途：任何会话发现「知识库维护问题」、且**不属于可顺手改**的，在这里留一条。
> 建立：2026-10-27 ｜ 消费方：本工作区的知识库维护会话

## 什么该报（大维护）

- 改 `00-索引` 路由表 / 改 `01-约定` / 改 `30-协作/*` 机制文件
- 动**索引台账段**（禁手改）
- **批量替换**、重命名 / 移动文件
- **结构性缺陷**：NUL 字节、权限、检查器误报、两条规矩打架

## 什么不必报（小维护：顺手改，然后写维护日志）

- 自己那篇的错字、坏链、水位过期
- 补一行自己的记录

## 一条一文件

文件名：`YYYY-MM-DD-<短问题>.md`，正文四行：

```text
发现者：
对象：
问题：
建议：（含紧急度：急 / 不急）
```

## 维护会话怎么消费（＝ `01-约定` §11.3）

1. **读动态**：每次进库**先扫本目录**，再看 `30-协作/60-维护日志.md`
2. **审阅 → 执行 → 归档**：处理完 → 移进 `_已处理/`
3. **跟踪**：还要继续跟的 → 转进 `20-操作/70-知识库维护备忘.md` §五
4. **记录**：管理员的动作进 `99-变更日志.md` —— **不要写 `60-维护日志.md`**（那是全体共写的**共同体日志**，见 §11.4）

> 完整流程：`01-约定` **§11.1** 判据 ｜ **§11.2** 共同维护（四步）｜ **§11.3** 管理员维护（五步）｜ **§11.4** 两个主体、两个日志
